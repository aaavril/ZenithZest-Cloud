Los conceptos del curso que aplicamos

Modelos de servicio

Serverless: Cloud Run Jobs corre el contenedor sin que administremos servidores.

Responsabilidad compartida

Google asegura la nube; nosotros, los permisos, los datos y la configuración.

Contenedores

La app viaja como imagen inmutable, versionada con el SHA del commit.

IaC declarativa

Terraform describe el estado deseado; el state guarda lo que existe.

CI/CD

Cada cambio pasa por pruebas y un plan revisado antes de aplicarse.

IAM y menor privilegio

Cada identidad, solo lo que necesita; GitHub entra sin claves (OIDC).

Observabilidad

Métricas, logs y alertas sobre lo que le importa al negocio.

FinOps

Presupuesto, etiquetas, escalar a cero y destruir lo que no se usa.

Bucket de Cloud Storage versionado, con bloqueo nativo; un state por entorno.

Un clic en destroy.yml y la evidencia de que el state quedó vacío.

¿Qué es VADER?

Un modelo de sentimiento gratuito que corre en la compu: suma el puntaje de cada palabra según un diccionario en inglés. Le agregamos unas 60 palabras en español.

Negativas: 40 de 40

Las quejas son claras para los dos modelos.

18 diferencias

Frases neutras que la API vio levemente positivas, como “sacó un sabor nuevo”.

Un “falso amigo”

Una palabra que se escribe igual en dos idiomas pero significa otra cosa. En inglés “sin” es “pecado”, así que VADER leyó “sin problema” como muy negativo. Al corregirlo, la coincidencia pasó de 85 % a 91 %.

16

Avril (12:15–12:45). El extra: comparar la API paga con un modelo local gratuito. VADER no entiende el idioma como la API: le da a cada palabra un puntaje de un diccionario (en inglés) y los suma. Le agregamos palabras en español como "excelente" o "pésimo". La primera comparación dio 85 % y encontramos por qué: "sin" en inglés significa "pecado", así que "sin problema" sonaba muy negativo. Eso es un falso amigo: se escribe igual en los dos idiomas pero significa otra cosa. Aprendizaje: un modelo pensado para otro idioma puede fallar en silencio, hay que mirar los ejemplos y no solo el porcentaje. Para qué sirve: a escala, VADER podría resolver lo obvio gratis y dejar a la API solo los casos dudosos. Limitación: los datos son sintéticos; con opiniones reales coincidiría menos. Detalle en docs/comparacion-modelos.md.
