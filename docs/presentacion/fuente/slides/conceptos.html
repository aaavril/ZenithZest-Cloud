Repaso rápido

Los conceptos del curso que aplicamos

Modelos de servicio

Serverless: Cloud Run Jobs corre el contenedor sin que administremos servidores.

Responsabilidad compartida

Google asegura la nube; nosotros, los permisos, los datos y la configuración.

Contenedores

La app viaja como imagen inmutable, versionada con el SHA del commit.

IaC declarativa

Terraform describe el estado deseado; el state guarda lo que existe.

CI/CD

Cada cambio pasa por pruebas y un plan revisado antes de aplicarse.

IAM y menor privilegio

Cada identidad, solo lo que necesita; GitHub entra sin claves (OIDC).

Observabilidad

Métricas, logs y alertas sobre lo que le importa al negocio.

FinOps

Presupuesto, etiquetas, escalar a cero y destruir lo que no se usa.
