Infraestructura como código

Las buenas prácticas que pide la consigna

State remoto con lock

Bucket de Cloud Storage versionado, con bloqueo nativo; un state por entorno.

Versiones fijadas

Terraform 1.9.8, provider ~> 6.0 y el lock file versionado en Git.

Etiquetas obligatorias

project · team · env · owner en todos los recursos, desde el provider.

Variables validadas

Tipo, descripción y validación en todas; rechaza un ID inválido o una imagen latest.

Imagen por SHA

Nunca latest: cada despliegue usa el commit exacto, y volver atrás es volver al commit anterior.

Destroy limpio

Un clic en destroy.yml y la evidencia de que el state quedó vacío.
