Todo con Terraform, en dos capas

Bootstrap: una sola vez, desde Cloud Shell (33 recursos). Entorno dev: lo aplica el pipeline, con 5 módulos por capacidad.

ZenithZest · Cloud Computing UCU

Avril (3:30–4:15). Ningún recurso se creó a mano por la consola, salvo el bootstrap del state y la carga del secreto, como permite la consigna. El bootstrap existe porque el pipeline necesita algo antes de poder entrar: el bucket del state, el registro de imágenes y la federación OIDC. Es el problema del huevo y la gallina. El entorno dev está en módulos por capacidad: storage, job, secret, scheduler y monitoring, conectados por sus outputs. Para producción se agrega envs/prod con los mismos módulos y otro .tfvars.
