Un “falso amigo”

Una palabra que se escribe igual en dos idiomas pero significa otra cosa. En inglés “sin” es “pecado”, así que VADER leyó “sin problema” como muy negativo. Al corregirlo, la coincidencia pasó de 85 % a 91 %.

Avril (12:15–12:45). El extra: comparar la API paga con un modelo local gratuito. VADER no entiende el idioma como la API: le da a cada palabra un puntaje de un diccionario (en inglés) y los suma. Le agregamos palabras en español como "excelente" o "pésimo". La primera comparación dio 85 % y encontramos por qué: "sin" en inglés significa "pecado", así que "sin problema" sonaba muy negativo. Eso es un falso amigo: se escribe igual en los dos idiomas pero significa otra cosa. Aprendizaje: un modelo pensado para otro idioma puede fallar en silencio, hay que mirar los ejemplos y no solo el porcentaje. Para qué sirve: a escala, VADER podría resolver lo obvio gratis y dejar a la API solo los casos dudosos. Limitación: los datos son sintéticos; con opiniones reales coincidiría menos.
